News & Feeds

Every feed remembers what it already posted — each item is posted exactly once, and only genuinely new content reaches your channels. On a fresh install the history is seeded silently and just the newest item is shown.

Game news

RA3 uses the current GameReplays portal. Generals Evolution uses its official ModDB article feed. New items are posted to the matching game's news channel; /news browses that game's archive.

ModDB

RA3 articles come from ModDB's RA3 articles page; Generals Evolution uses its official articles and downloads feeds. Posting is rate-limited per game (at most one post per 6 hours, newest first) so bursts never flood the channel. /mods lists the newest entries on demand.

Twitch

The notifier checks the Red Alert 3 category and classifies stream titles for the selected game. Servers can additionally track specific streamers via /notifications.

YouTube

Uploads are tracked through YouTube's free RSS feeds — no API key and no quota. Posts use a large preview and are filtered for the selected game; servers can add their own channels via /notifications.

Managing feeds

  • /notifications — per-guild channels, tracked streamers, and admin Test Post buttons.
  • /toggle — enable/disable each feed per server.
  • /test_channels — verify the bot can actually post in every configured channel.
