News & Feeds

Every feed remembers what it already posted — each item is posted exactly once, and only genuinely new content reaches your channels. On a fresh install the history is seeded silently and just the newest item is shown.

Game news

The current GameReplays RA3 portal, with older per-game feeds retained for supported non-RA3 games. New items are posted to the news channel as they appear; /news browses the archive.

ModDB

Current RA3 mod updates and articles from ModDB's RA3 articles page. Posting is rate-limited (at most one post per 6 hours, newest first) so bursts never flood the channel. /mods lists the newest entries on demand.

Twitch

The notifier polls the whole Red Alert 3 category — every live RA3 stream gets announced, including Sybert's. Servers can additionally track specific streamers via /notifications.

YouTube

Uploads are tracked through YouTube's free RSS feeds — no API key, no quota. Community channels are followed for every server automatically (Sybert's BattleCast channel); servers can add their own via /notifications.

Managing feeds

  • /notifications — per-guild channels, tracked streamers, and admin Test Post buttons.
  • /toggle — enable/disable each feed per server.
  • /test_channels — verify the bot can actually post in every configured channel.
