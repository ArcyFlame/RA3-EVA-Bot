Self-Hosting

E.V.A is a Node.js + TypeScript application with an SQLite database — one process, no external services required.

Requirements

  • Node.js 20.18.1 or newer
  • A Discord bot token (Developer Portal → Bot)
  • Optional: Challonge API key, Twitch app credentials

Install & run

git clone <repository>
cd ra3-eva-bot
npm install
cp .env.example .env    # fill in DISCORD_TOKEN
npm run build
node dist/index.js

.env.example documents every variable. Only DISCORD_TOKEN is required — everything else degrades gracefully. npm run diagnose checks the configuration and reports anything missing.

Useful scripts

Script Purpose
npm run build Compile to dist/
npm run typecheck TypeScript check
npm test Test suite (vitest)
npm run diagnose Configuration diagnostics
npm run seed:masters Seed the Hall of Fame list

Data

Everything is stored in a single SQLite file (data/bot.db, WAL mode). Migrations run automatically at boot. The Red Alert font for the charts lives in fonts/.

YouTube notifications work key-free through RSS polling. The optional PubSubHubbub push mode needs a public callback URL — see YOUTUBE_CALLBACK_BASE in .env.example.
