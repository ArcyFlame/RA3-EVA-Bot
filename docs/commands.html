Commands

Every command is also listed in /help, grouped the same way. Admins can hide categories per server in /toggle. Safe public commands can also be used in DMs by default; the bot owner can disable that from the same feature menu.

Tournaments

CommandWhat it does
/eventsBrowse tournament announcements with Sign Up / Results buttons
/resultsPodium + standings from every discovered Challonge bracket
/matchesThe current bracket: standings when finished, up-next while running
/pickmap [event]Pick a verified map from the current or selected tournament
/checkin [event]Open the check-in board; referees also get management controls
/report_score <opponent> <factions> <score>Submit a checked-in tournament result for referee review
/tournaments_scanForce an immediate portal + forum scan admin
/tournament_linkAttach a Challonge bracket by URL admin
/add_master / /remove_master / /list_mastersHall of Fame management admin
