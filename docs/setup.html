Setup

Getting E.V.A running in your server takes about two minutes. Everything is configured through Discord — no dashboard, no config files.

1. First steps

  1. Add the bot to your server with the invite link provided by the owner.
  2. Run /bot_setup — the setup wizard opens with buttons.
  3. Pick your admin role and referee role (tournament officials who can run check-ins).
  4. Under Notification Channels, choose where news, ModDB posts, tournament announcements, Twitch/YouTube posts and the lobby board should go. You can also skip channels you don't want.
  5. Choose your server's game: RA3 or Generals Evolution — feeds, artwork, maps and stats sections adapt automatically.

2. Recommended channels

Channel What lands there
# tournaments Tournament announcements with a Sign Up button, results discovery
# news Current news for the selected game
# mods Game-specific ModDB articles and updates (rate-limited, no spam)
# streams Twitch streams and YouTube uploads (Sybert's BattleCasts included)
# stats The persistent Live Stats panel with charts (/stats_panel set)

3. Verify everything works

Run /test_channels (admin). The bot checks every configured channel — existence, permissions, and an actual test post (auto-deleted) — and reports a checklist. The Test Posts button in /notifications runs the same check.

4. Daily commands

/help shows every command grouped by category; admins can hide categories per server in /toggle. The pages in this section of the docs explain the tournament pipeline, stats and notification feeds in depth.

Players use /link to choose Shatabrick or RA3BattleNet, then add a nickname or profile id. The two platforms remain separate account systems and are never cross-looked-up.
